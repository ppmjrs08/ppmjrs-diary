# M2 课程推荐设计

2026-10-14。权威范围：最新 SmartCampus proposal 和成员职责表；旧五人执行指南的测验模块已被课程推荐替换。用户要求现在开始、使用 Java、本地独立文件夹、上传本人公开 GitHub。

## 目标
学生登录，填写英文兴趣与学习目标；系统从数据库读取本人已修课程，排除已修、停用、先修不足课程；Java TF-IDF/cosine 返回最多三门课程、匹配词及资格解释。学生只能读取本人档案和推荐历史。页面有加载、错误、空结果和历史记录。

## 实现选择
独立 Spring Boot 3.5.3 / Java 17+ 模块，MyBatis-Plus 3.5.12。这些版本有本机缓存，用于本机课程原型，公网部署前升级并评估安全。页面用原生 HTML/CSS/JS，省去旧 Vue 工程安装阻塞；后端为 Java。API 可被团队 Vue 调用。

默认 demo：H2 文件数据库、20 门虚构课程、两个固定虚构学生、本机 session 登录与 CSRF 校验；绑定 127.0.0.1。mysql 配置：关闭自动建表与种子初始化，关闭演示登录，使用环境配置的不可猜测 bearer token 与学生编号映射作为临时团队认证桥。最终统一认证通过 StudentIdentity 接口替换。数据库成员持有公共用户及成绩表，M2 不修改已修成绩。

M2 提供独立表契约及 MySQL SQL 草案，组员可映射到共同表。缓存不是首版必需，不依赖 Redis/Nacos。推荐历史最多读取最近 20 条，每次生成保存真实结果。数据修改后重新读取和计算，不缓存旧课程。

## 验收
算法排序/资格/边界测试；真实 HTTP 登录、本人档案、伪造 studentId 和 completed 字段拒绝、跨用户历史隔离、CSRF 与退出测试；H2 持久化重启；20 个合成评价档案与关键词基线比较；浏览器实测。真实 MySQL 与团队统一认证联调待组员提供配置，不冒充已验证。

## 限制
英文精确词元匹配，无语义向量/LLM，不宣称理解中文或真实选课有效性。20 档案为合成固定集，未由学生专家审阅，不能当作真实效果评价。输出是建议，不自动报名。
